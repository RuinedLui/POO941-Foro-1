# POO941-Foro-1
## Descripción

Este proyecto fue desarrollado para el Foro 1 de la asignatura Programación Orientada a Objetos de UDB Virtual.

El programa permite almacenar y administrar información de estudiantes de UDB Virtual mediante una colección Map<String, String>.

## Objetivo

Aplicar los conocimientos sobre colecciones en Java mediante el desarrollo de un programa que permita ingresar, buscar, eliminar y mostrar estudiantes de UDB Virtual.

## Colección utilizada:

Para el desarrollo del programa se utiliza la estructura Map, específicamente una implementación HashMap.

La colección utilizada es Map<String, String>.

El carnet del estudiante se utiliza como clave y el nombre completo del estudiante como valor.

Ejemplo:

Carnet → Nombre completo

CD260338 → Adriana Liseyda Cortez de la Cruz

SG260385 → Marlon Enrique Santiago Garcia

## Funcionalidades

El programa cuenta con un menú que permite realizar las siguientes operaciones:

Ingresar alumno:
solicita el carnet y el nombre completo del estudiante y almacena la información en el Map.

Buscar alumno:
permite buscar un estudiante utilizando su carnet.

Si el carnet no existe, muestra un mensaje indicando que el alumno no fue encontrado.

Eliminar alumno:
permite eliminar un estudiante utilizando su carnet.

Si el carnet no existe, muestra un mensaje indicando que el alumno no fue encontrado.

Mostrar todos los alumnos:
Muestra todos los estudiantes almacenados en el programa.

Salir:
finaliza la ejecución del programa.

## Tecnologías utilizadas

## Ejecución

Para ejecutar el proyecto:

Tener instalado Java JDK 26.

Abrir Apache NetBeans.

Seleccionar la opción para abrir un proyecto existente.

Seleccionar la carpeta POO941-Foro-1.

Ejecutar el archivo Foro_1.java.

Seleccionar una opción del menú y seguir las instrucciones mostradas por el programa.
